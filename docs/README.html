Private product foundation

PointApp Builder

Role-governed content authoring and release infrastructure for the Point Community Church phone and tablet application.

Foundation status

The repository currently contains the product specification, versioned content and release contracts, a responsive Builder shell, a phone/tablet staging preview, and quality automation. Collaborative persistence, protected API services, PointApp integration, and Production publishing remain intentionally disconnected.

Start locally

  1. Install Node.js 22.13 or newer.
  2. Run npm ci.
  3. Run npm run dev.
  4. Run npm run check and npm run test:e2e before review.

Source map

  • src/content — mobile-safe data contracts.
  • src/domain — authorization and release policy.
  • src/preview — renderer used by the staging canvas.
  • src/client — separate Builder panels and workspace shell.
  • specs/001-foundation/spec.html — governing foundation specification.
  • docs/architecture.html — system boundaries and delivery path.

Hosting status

The private repository deploys to a dedicated Cloudflare Worker at appbuilder.pointatx.org. The Worker serves the compiled client, reports health through an isolated D1 binding, and fails closed for unfinished API and authentication routes. Authentication, collaborative drafts, PointApp delivery, and Production publishing remain intentionally disabled.
