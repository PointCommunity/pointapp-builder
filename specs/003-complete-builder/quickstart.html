Engineering quickstart

Reproduce the Builder locally.

These workflows use deterministic local identities and a local D1 database. Local auth fixtures must refuse non-loopback requests and must never be configured in the deployed Worker.

Prerequisites

  • Node.js 22.13 or later and npm.
  • Repository checkout on codex/003-complete-builder while developing; deployment is only from reviewed main.
  • Cloudflare credentials are required only for remote migration/deployment.

Install and initialize

npm ci
npm run db:migrate:local
npm run dev

The local server prints its loopback URL. It must not print secrets, tokens, or signed cookies.

Identity scenarios

Bootstrap Owner: use fixture GitHub ID 1202831; the first local login creates an Active Owner.

Pending Editor: use any other fixture ID; the session may view only its pending state until the Owner approves it.

Role matrix: seed deterministic Editor, Publisher, Administrator, Owner, Pending, and Disabled identities through the test-only fixture helper.

Core integration journey

  1. Sign in as bootstrap Owner and confirm the server reports the real membership; no role selector exists.
  2. Approve a Pending Editor, assign Editor, then verify immediate access without a new OAuth round trip.
  3. Create a draft; configure branding, settings, audiences, navigation, screens, all supported element types, accessible media, and one notification campaign.
  4. Save a revision, reload it, and verify a stale-parent save is rejected without data loss.
  5. As Publisher, publish that exact revision to PointApp Staging.
  6. As Administrator, promote current Staging to Production and compare manifest digests byte-for-byte.
  7. Fetch the anonymous Production endpoint, public key, and referenced media; verify unrelated draft media is denied.
  8. Repeat the Production fetch with If-None-Match and expect 304.
  9. As Owner, publish another candidate and roll back to the prior Production release with a reason.

Required local gates

npm run format:check
npm run types:check
npm run typecheck
npm run lint -- --max-warnings=0
npm run contract:check
npm run db:migrate:test
npm run test:coverage
npm run build
npm audit --audit-level=high
npm run test:performance
npm run test:e2e

No skipped or quarantined failing tests count as green.

Production rule

After review, merge to main, confirm the exact commit is clean and green in GitHub Actions, apply the forward migration, deploy that exact commit directly to appbuilder.pointatx.org, and run live endpoint plus browser verification. The Builder has no canary/staging deployment.
