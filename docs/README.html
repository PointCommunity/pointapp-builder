Production control plane

PointApp Builder

Role-governed content authoring and release infrastructure for the Point Community Church phone and tablet application.

Implemented system

The private repository contains GitHub App authentication, server-enforced access, persistent drafts and media, immutable revisions, signed PointApp Staging and Production channels, exact-candidate promotion, rollback, audit operations, and phone/tablet previews. Installed PointApps consume the public signed Production content contract; native app code and app-store delivery remain separate.

Start locally

  1. Install Node.js 22.13 or newer.
  2. Run npm ci.
  3. Copy .dev.vars.example to a local untracked .dev.vars.
  4. Run npm run db:migrate:local, then npm run dev.
  5. Use the loopback-only /auth/dev fixture for deterministic role testing.
  6. Run npm run check and npm run test:e2e before review.

Source map

  • src/content — mobile-safe data contracts.
  • src/domain — authorization and release policy.
  • src/preview — renderer used by the staging canvas.
  • src/client — separate Builder panels and workspace shell.
  • src/server — protected Worker API, persistence, signing, and audit.
  • specs/003-complete-builder/spec.html — governing product specification.
  • docs/architecture.html — system boundaries and delivery path.

Hosting status

The private repository deploys directly to one Production Cloudflare Worker at appbuilder.pointatx.org. GitHub Pages cannot supply the protected Worker API, D1 persistence, or secret-held signing required by this Builder. There is no Builder staging/canary environment. The existing organization GitHub App authenticates users; GitHub user 1202831 is the only bootstrap Owner, and every other verified GitHub identity begins as a pending Editor with no protected access.

Release distinction

Deploying this Builder updates the Builder Production service. Publishing inside the Builder instead advances PointApp content from an immutable draft revision to PointApp Staging and then, after Administrator or Owner approval, to PointApp Production. Online devices receive changed content on launch or their next configured refresh; executable features still require Apple App Store and Google Play releases.
