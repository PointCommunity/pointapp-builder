The Builder is a control plane for versioned content. It does not become a second app store and it does not write directly into the PointApp repository.

Separated responsibilities

GitHub Pages client

Loads the authenticated workspace from an API, renders controls and previews, and holds no privileged credentials.

Builder API

Authenticates collaborators, enforces roles, stores revisions, coordinates releases, audits mutations, and signs approved envelopes.

Content delivery

Serves immutable Staging and Production envelopes over HTTPS with cache controls and rollback-safe identifiers.

Installed PointApp

Ships native renderers and capabilities through stores, then accepts only compatible data manifests from the release channel.

Why data-only updates

Apple’s review rules prohibit downloaded code that changes app features or functionality, and Google Play prohibits self-updates or executable code fetched outside Play. PointApp content therefore uses a finite, versioned element vocabulary implemented inside the reviewed native binary. New native capabilities require normal store releases.

Hosting constraint

GitHub documents private Pages access for Enterprise Cloud and private-repository Pages availability on paid plans. The current PointCommunity organization reports the Free plan. The repository stays private, so the Pages deployment remains gated until the organization plan changes or another host is explicitly approved.
